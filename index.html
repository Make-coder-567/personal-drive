自定义域名

当前访问地址：

真正的域名绑定（DNS + HTTPS 证书）需在 WorkBuddy「设置 → 数据管理 → 应用」或 EdgeOne 控制台完成。本页负责：保存配置、校验格式、检测解析与存储路径是否生效。

  1. 在 WorkBuddy「设置 → 数据管理 → 应用」或 EdgeOne 控制台进入「域名管理」，添加你的域名（建议用子域名，如 drive.example.com）。
  2. 平台会给出 CNAME 目标（形如 xxx.eo.dnse.com）。
  3. 到域名服务商添加记录：类型 CNAME，主机记录填子域名前缀（如 drive），记录值填平台给的 CNAME 目标，TTL 600。
  4. 不要使用按线路/地域解析；等待 5–10 分钟生效（最长 48 小时）。
  5. 在平台申请免费 HTTPS 证书（TrustAsia / Let's Encrypt），等待状态变为“已部署”。
  6. 用新域名打开本应用，确认能登录、上传、下载；特别注意 /.cloud/storage/ 同源请求也必须正常。

常见失败：CNAME 未生效、证书未签发、域名 CAA 记录未放行 CA、DNSSEC 异常、或把域名直接绑到 EdgeOne Pages 裸项目导致 /.cloud/storage/ 未被代理。

页面更新后如果没看到变化，请按 Ctrl + Shift + R（macOS：Cmd + Shift + R）硬刷新，确保加载最新版本。

0. ⚡ 加速器（推荐）

  • 点顶部 「⚡ 加速器」 打开任务面板，或用工具栏 「⚡ 加速上传」、文件卡片上的 「⚡ 加速」 发起传输。加速上传同样可先选择目标目录。
  • 下载优先使用签名直链直连对象存储（更快），失败自动回退到原通道；桌面端边下边写不占内存，手机端交给原生下载管理器。
  • 任务面板显示每个任务的进度、实时速度、剩余时间；可暂停 / 取消 / 失败重试 / 移除，顶部显示合计速度。
  • 点面板里的 ⚙ 调整分片大小、上传/下载并发、同时文件数、重试次数、超时；提供标准 / 极速 / 省流三种预设。
  • 设置里的「开始测速」会实测普通通道与加速通道的上传吞吐（约 32MB，自动清理），并自动选择后端允许的最快封装方式。
  • 加速器与原上传下载共用同一账号、权限和数据：加速上传的文件在普通视图中立即可见，反之亦然。设置只影响加速器任务，不改变原有流程。
  • 为什么有时感觉不快？上传都要经过同一个应用网关（与下载直连对象存储不同），速度上限由网关与你的上行带宽决定；加速器通过多连接并发来逼近这个上限，若已达带宽上限则两者接近属正常。
  • 上传很慢 / 长时间停在 0 B？请先点测速看「实测上行」。速度就是上限：1 MB/s 时 450MB 约需 7~8 分钟，属正常。慢网会自动用小分片，并用实测速度显示可信进度与剩余时间。
  • 出现「Failed to fetch」/ 测速超时？新版已降低默认并发（16→8）减少连接重置，并对瞬时失败的分片自动重试而非整单失败；测速会自动避开正在运行的任务。若仍失败，请暂停其它传输、确认网络稳定后点任务上的「重试」；或点「取消」改用普通「上传文件」（数据完全通用）。

1. 上传文件 / 文件夹

  • 点击 「上传文件」 或 「上传文件夹」 会先弹出 「选择上传位置」：默认选中当前目录，也可选根目录或任意层级目录，确认后再选择本地文件。
  • 直接拖拽文件到页面也会先询问上传位置；取消即放弃本次上传。
  • 「上传文件夹」 会在所选目录下保留目录结构；上传完成后自动进入上传的根文件夹。
  • 大文件自动分片、支持断点续传：失败或刷新后重新选同一文件，会从已传分片继续。
  • 右下角任务面板显示进度；点 「取消」 可停止，已传分片会保留。面板被收起时，点顶部 「任务」 重新打开。
  • 「设置」 可调分片大小与并发；大文件上传前会自动探测网关允许的最大分片。

2. 移动文件 / 文件夹

  • 文件或文件夹卡片点 「移动」，在树形目录中选择目标文件夹后点 「确认移动」；可选根目录或任意层级目录。
  • 移动只修改云端目录关系，不会重传文件，文件夹内的所有内容会整体跟随。
  • 校验不通过时确认按钮保持禁用：目标目录不存在、已在目标目录、目标有同名项目、或把文件夹移动到它自己/子目录。
  • 同名项目一律拒绝，不会静默覆盖；请先改名或另选目录。若保存失败会自动恢复原位置。

3. 下载

  • 文件卡片点 「下载」：并行下载并显示实时 MB/s，可随时取消。
  • Chrome/Edge 会直接写入你选择的位置，所以不会出现在浏览器下载记录里，请到保存位置查看。
  • 文件夹点 「下载」 会打包成 ZIP，任务面板显示进度，可取消。
  • 取消后已写入的部分文件会保留，但文件不完整。

4. 分享文件 / 文件夹

  • 文件或文件夹卡片点 「分享」，选择有效期（1/3/5/7/9/11/13/15 小时）后生成短链接。
  • 接收方打开链接：单文件可直接下载；多分片文件可点 「高速下载（原生）」；文件夹可逐个下载或打包 ZIP。
  • 链接过期需重新生成；大文件建议选更长有效期，避免下载到一半 401。
  • 分享链接指向云端清单，文件本身不会重复上传。

5. 校验与诊断

  • 「校验文件夹」：选择本地同一文件夹，比对云端元数据，显示已上传 / 缺失 / 大小不一致（不重传）。
  • 「诊断」：查看 list、签名、公开 URL 与前几个文件的分片完整性。
  • 出现 403 多半是登录过期：点 「退出」 重新登录后再试。

6. 自定义域名

  • 点顶部 「域名」：保存域名、校验格式、检测解析与 /.cloud/storage/ 是否可用。
  • 真正的绑定（CNAME + HTTPS 证书）在 WorkBuddy「设置 → 数据管理 → 应用」或 EdgeOne 控制台完成。
  • 建议用子域名（如 drive.example.com）；大陆加速需要 ICP 备案。

7. 常见问题

页面还是旧版 / 改动没生效？

按 Ctrl + Shift + R（macOS 为 Cmd + Shift + R）硬刷新；或关闭标签页后用无痕窗口打开。仍不行就清除该站点缓存再试。

上传失败 / 卡住怎么办？

看任务面板的错误信息；多半是网络或限流。重新选同一文件会续传；并发过高时可在「设置」调低。403 请退出重登。

分享下载提示 401 / 分片失败？

签名链接过期。让分享者重新生成更长有效期的链接，或把大文件拆分后分享。

手机下载大文件提示不支持？

手机浏览器没有桌面版的流式落盘能力。请点「高速下载（原生）」（Service Worker 流式）；单文件也可用原生直链。iOS 若仍无反应，请用电脑下载。

点了取消为什么还在跑？

正在传输的分片无法中断，取消只会停止后续分片；等在途分片结束就会停（状态显示“正在取消…”）。

文件夹下载没有出现在下载记录？

Chrome/Edge 直接写入你选择的位置，不经过下载管理器；请到保存位置查看。任务面板里有进度。

域名检测失败？

常见原因：CNAME 未生效、证书未部署、分线路解析、或自定义域名没有代理 /.cloud/storage/。按「域名」弹窗里的步骤逐项检查。

首次登录会自动显示本帮助，关闭后不再自动弹出。
