如何校验下载文件？ 
Windows PowerShell:
Get-FileHash .\个人云盘-1.0.0-release.apk -Algorithm SHA256

macOS / Linux:
shasum -a 256 个人云盘-1.0.0-release.apk
Android 安装失败怎么办？

如果手机上曾安装调试版 APK，由于签名不同，需要先卸载旧应用再安装正式版。安装时请允许“未知来源安装”。

Windows 出现 SmartScreen 怎么办？

当前 Windows 包未签名，属于预期提示。正式发布时应购买 Authenticode 代码签名证书，重新构建签名版并替换 GitHub Release 资产。
